Synesthetica is a real-time music visualiser. It listens to MIDI or audio and draws it from the perspective of Western music theory. It can be viewed directly as a web page or operated through an LLM, which presents various advantages. Everything is better explained on the [github repo](https://github.com/nicc/synesthetica#synesthetica).

Select an input and feed it music to get started. Give it a BPM to see a representation of time. Tell it what key you're in to see functional harmony. These are in the Basics tab.

Explore the controls or tell your LLM what you're trying to achieve. If you're using an LLM, don't be afraid to ask about what (or how) you're playing. It can access about an hour of sustained piano playing history.

The brave and curious will find the full primer presented by the MCP server to LLMs below.
